## Descripción del taller

Este taller contiene ejercicios realizados en Java sobre arreglos, matrices y ArrayList.

Los ejercicios están organizados en tres carpetas:

- `arreglos`: ejercicios con arreglos unidimensionales.
- `arraylist`: ejercicios utilizando ArrayList.
- `matrices`: ejercicios con arreglos bidimensionales y matrices.

## Instrucciones para ejecutar el programa

1. Descargar o clonar este repositorio.
2. Abrir el proyecto en NetBeans o Visual Studio Code.
3. Abrir la carpeta `src`.
4. Entrar a la carpeta correspondiente al ejercicio.
5. Abrir el archivo `.java` que se desea ejecutar.
6. Ejecutar el programa.
7. Seguir las instrucciones que aparecen en la consola.
